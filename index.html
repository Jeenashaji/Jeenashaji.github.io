Research Assistant – Master's Thesis

German Aerospace Center (DLR) · Oct 2025 – Present
S

Situation

Optimization models of industrial heating systems run over a full year of hourly data (8,760 hours) and get slow. Time-series aggregation shrinks the input, but it is unclear which method still gives reliable investment decisions.

T

Task

Compare aggregation methods by their effect on the optimization results, not only by how well they reproduce the input data.

A

Action

  • Implemented six aggregation methods (including TSAM, hierarchical and distance-based clustering) across a 32-configuration sweep, evaluated with nRMSE, RMSE, duration curves and residual metrics against a full-year reference.
  • Built LP/MILP models in Python (oemof.solph, Pyomo, HiGHS, TESPy).
  • Refactored research notebooks into a modular Python package (13 modules, CLI, unit tests) with a single results schema for reproducible benchmarking.
  • Built a Streamlit app that lets engineers compare steam-system scenarios.
R

Result

  • The method with the best nRMSE gave the worst storage sizing (r = −0.96).
  • A quantile-based representation I designed cut storage-sizing error from −17% / −30% to below 2%.
  • Engineers can compare scenarios in the app instead of running them manually.
Time-Series ClusteringLP/MILPPyomoStreamlit

Physics-Informed Predictive Maintenance

Funded research project, University of Oldenburg · 2026 – Present
S

Situation

Labelled failure data for power-electronics equipment is rare, so purely data-driven fault prediction is hard to train and to trust.

T

Task

Build a prediction approach that works with mostly healthy operating data, and make the output usable for service teams.

A

Action

  • Developing PyTorch models on 5-minute telemetry (16,799 observations in the current research dataset); version 1 combines an LSTM branch with a physics branch and is trained on healthy data only.
  • Built physical degradation relationships into the approach: Arrhenius (temperature-driven ageing) and Coffin–Manson (thermal-cycling fatigue).
  • Investigated wavelet transforms for degradation and fault patterns, efficiency behaviour and data normalisation across manufacturers.
  • Structured the code as a tested Python package (data, features, models, physics, diagnosis, evaluation) with GitLab CI for tests and linting. A co-founder contributed fault-simulation datasets and physics validation.
R

Result

  • A working version 1 model and a monitoring dashboard (fleet health, warranty tracking, automated reports) with the model running in the background. Validation on real fault data is ongoing.
PyTorchLSTMPhysics-Informed MLWavelets
