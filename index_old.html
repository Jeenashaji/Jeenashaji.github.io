TechNav — Neural Execution Engine

2025 – Ongoing Live Prototype Interactive Decision Engine

Project Overview

TechNav is an interactive decision engine that transforms how entrepreneurs and creators navigate the overwhelming landscape of tools, platforms, and strategies. Instead of static lists, users answer a series of plain-language questions about their goals, constraints, and current stage — and receive a personalized, end-to-end execution flow.

The system covers 6 pillars (Build a Startup, Sell Digital Products, Automate Workflows, Build a Creator Page, Use AI Effectively, Earn Money Online) with 40+ mapped tools, branching decision trees, and infinite flow combinations.

Key Features

  • 3D Ring Selector: An interactive 3D carousel built with CSS transforms for selecting your journey pillar
  • Branching Decision Trees: Dynamic question paths that adapt based on previous answers — no two flows are identical
  • Tool Intelligence: Each recommended tool includes pros, cons, cost, skill level, skip signals, and alternatives
  • Prompt Library: Ready-to-copy prompts following a 5-part structure (Role → Task → Audience → Constraints → Format)
  • Resource Playbooks: Curated resources like "50 Digital Product Ideas", "15-Hour Launch Sprint", and "Tool Tier Lists"
  • Progressive Disclosure: Free plan shows full flow + first 2 steps; Pro unlocks all steps and prompts
  • WebGL Background: Three.js particle cloud with mouse-reactive camera for immersive atmosphere

Technical Implementation

  • Built entirely in vanilla HTML/CSS/JS — no frameworks, no build step
  • Three.js for the WebGL particle cloud background with additive blending and fog
  • CSS 3D transforms for the ring selector with snap-to-card behavior
  • State machine for question flow management with history/backtracking
  • Dynamic content generation based on user answers — no hardcoded paths
  • Modal system for tool deep-dives with copy-to-clipboard prompts
  • Responsive design with reduced-motion support for accessibility
